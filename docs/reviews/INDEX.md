# docs/reviews — архив ревью и операционных отчётов

Единый архив отчётов проекта «Метеостанция дачного дома» и сопутствующей
инфраструктуры (сеть, мониторинг). Назначение: **постоянный контекст для
ИИ-ревьюеров (GLM и др.)** — владелец даёт в новом чате ссылку на эту папку,
и агент восстанавливает картину по индексу + TL;DR, углубляясь в детали
только там, где нужно.

## Правила ведения

1. **Имя файла:** `YYYY-MM-DD-<тема>.md`. Дата = дата события (MSK), а не дата
   публикации. Файлы сортируются по имени — это и есть хронология. История
   правок ведётся самим git (`git log -- docs/reviews/`).
2. **Шапка файла** — машиночитаемый front-matter, затем сразу TL;DR:

   ```markdown
   ---
   date: 2026-09-22
   scope: ночной обзор погода+сеть (vitele)
   status: ok          # ok / resolved / watching / open
   ---
   ## TL;DR
   3–5 строк — главный вывод.
   ## Детали
   ...
   ## Хвосты и решения
   ...
   ```
3. **Гигиена (репо публичный):** никаких паролей, токенов, коммьюнити-строк и
   ключей. Внутренние адреса RFC1918 (192.168.8.0/24, 10.147.17.x) разрешены.
   Креды и схемы доступов живут только в приватном репо dacha-net.
4. Новая запись = новый файл + строка в таблице ниже (добавлять в конец
   соответствующего месяца, не переписывать старое).
